# CyberCodix CRM Help Center

A responsive Node.js + Express documentation website for CyberCodix CRM.

## Run locally

1. Install Node.js 18+.
2. Open this folder in a terminal.
3. Run:

   npm install
   npm start

4. Open http://localhost:3000

## Project structure

- server.js — Express server
- public/index.html — Help Center page
- public/styles.css — Responsive UI
- public/app.js — Search, category interactions and article modal
- public/cybercodix-logo.png — Cleaned CyberCodix logo without the "IT Solutions" tagline

## Production

For Hostinger or another Node.js host:
- Upload the project.
- Run `npm install`.
- Start the Node.js application with `npm start`.
- Point the domain/subdomain to the application's port according to your host's Node.js application settings.
